
# SLM Chatbot

## About the Project
This project is a simple chatbot built using a Small Language Model (SLM).

## Technologies Used
- Python
- Hugging Face Transformers
- SmolLM2-360M-Instruct

## Features
- Accepts user questions in the terminal
- Generates AI-based responses
- Runs locally using Python

## How to Run
1. Install the required libraries:
   pip install torch transformers

2. Run the chatbot:
   python main.py

3. Type `exit` to close the chatbot.
